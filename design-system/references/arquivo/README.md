# Arquivo documental

Este diretório guarda a extração CSS do MC-DESIGN-13 para rastrear decisões e conferir equivalência do Claro. As declarações antigas e seus valores repetidos são evidência da origem. A fonte dos estilos atuais está nos [tokens vigentes](../../TOKENS.md) e nos [manifestos de tema](../../themes/README.md).

O MC-DESIGN-SYSTEM-01 está registrado no commit [2c6cfef](https://github.com/consul4/multicurso-preview/commit/2c6cfef05b6abbe461570b14e08757768567282c). A descrição de uma arquitetura com um único tema foi substituída pela observação dos três temas em execução. Os pareceres e as referências anteriores continuam disponíveis como registros de aprovação e evidência, com o alcance original. [Referências](../README.md)

A entrega operacional DS02 e suas regras de manutenção ficam no [commit auditado ccb61b4](https://github.com/consul4/multicurso-preview/tree/ccb61b4ed8af7d12432404881dc3bf74fe8f8e7d/design-system). O relatório e os manuais ativos são os do [DS03](../../README.md).
