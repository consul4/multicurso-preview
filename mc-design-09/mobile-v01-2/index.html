Anatomia do prompt

Entenda os elementos de um prompt eficiente e como estruturá-lo para obter melhores resultados.

O que é um prompt?

É uma instrução que você fornece a uma IA para obter uma resposta específica, útil e de qualidade.

Exemplo prático

“Explique a inteligência artificial de forma simples e com três exemplos do dia a dia.”

Os 4 elementos do prompt

Um prompt eficiente é construído a partir de quatro elementos principais:

Objetivo
Define com clareza o que você quer obter.
Contexto
Fornece as informações necessárias.
Critérios
Estabelece regras e qualidade da resposta.
Formato
Indica como a resposta deve ser apresentada (ex.: lista, resumo, tabela).

Do pedido à instrução

Compare “Ajude com a reunião” com esta versão: “Escreva um aviso para a equipe informando que a reunião de terça mudou das 14h para as 16h. Use até três frases e confirme que o local permanece o mesmo.”

O objetivo é avisar. O contexto é a reunião da equipe. O limite de três frases e a informação sobre o local são critérios. O formato é um aviso curto.
